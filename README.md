# Rogai Snacks website

Static site (HTML, CSS and JS, no build step) for Bananas Rogai: USDA Organic plantain chips from Ecuador.

## View locally

Open `index.html` in a browser, or serve the folder (for example `python -m http.server 8080`).

## Deploy

Published with GitHub Pages from the `main` branch, root folder. `.nojekyll` disables Jekyll.
